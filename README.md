# 📖 About This Project

This is my personal portfolio website showcasing my work as an **AI/ML Engineer and Senior Research Fellow** at the University of Sheffield. The site highlights my research in **multimodal AI**, **speech processing**, **healthcare AI**, and **clinical deployment**.

## 🎯 Key Features

- ✨ **Typed.js animated intro** on the homepage
- 🌓 **Dark/Light theme** with system preference detection
- 📱 **Fully responsive** (mobile, tablet, desktop)
- 📰 **Latest news feed** (LinkedIn posts integration)
- 🛠️ **Animated skills marquee** with technology icons
- 📄 **Detailed CV pages**: Bio, Work Experience, Projects, Research
- 🔗 **Social links** (LinkedIn, GitHub, Google Scholar, ORCID, Twitter/X, ResearchGate)
- 🚀 **CI/CD** with GitHub Actions – automated deployment to GitHub Pages

# 🚀 Getting Started

## Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later)
- [npm](https://www.npmjs.com/) or [Yarn](https://yarnpkg.com/)

## Installation

```bash
# Clone the repository
git clone https://github.com/Madhurananda/madhurananda.github.io.git

# Navigate to the project directory
cd madhurananda.github.io

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open your browser and visit:

```
http://localhost:3000
```

to view the website locally.

## Build for Production

```bash
npm run build
```

## Export Static Files (if required)

```bash
npm run export
```

# 🌐 Deployment

This website is automatically deployed to **GitHub Pages** using **GitHub Actions** whenever changes are pushed to the `main` branch.

## Deployment Workflow

1. Push changes to the `main` branch.
2. GitHub Actions automatically installs dependencies.
3. The project is built using:

```bash
npm run build
```

4. The generated static site is deployed to GitHub Pages.
5. The updated website becomes available at:

**https://madhurananda.github.io**
